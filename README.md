# codegenesis
第一个全由个人开发的项目：
AI Agent 协作式软件开发平台 —— 输入需求，多个 AI Agent 自动协作完成设计、编码、测试、部署。

## 技术栈

- **后端**: Python + FastAPI
- **AI**: LangChain + LangGraph + DeepSeek
- **数据库**: PostgreSQL + Redis
- **前端**: React + TypeScript
- **基础设施**: Docker + Docker Compose

## 项目结构
backend/ — FastAPI 后端服务
frontend/ — React 前端
docs/ — 文档和学习笔记
