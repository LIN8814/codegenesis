# Week 03 总结

## 学了什么
- HTTP 协议：请求方法（GET/POST/PUT/DELETE）、状态码（200/201/204/404/405/422）、RESTful 设计
- FastAPI：CRUD API、路径参数、Swagger 自动文档
- Pydantic：数据验证、field_validator、model_validator、Literal
- LLM 对接：DeepSeek API、LLMClient 封装、prompt 设计
- 配置管理：.env、pydantic-settings、开发/生产环境配置
- Docker：容器化 FastAPI、镜像构建、端口映射、环境变量注入
- 工具链：APIFOX 调试 API、虚拟环境 venv、start.sh 脚本一键启动

## 有信心的地方
- 完整 CRUD API 能独立实现和调试
- 真实调用大模型生成代码（AI Agent 雏形）
- 项目能用 Docker 容器部署运行

## 卡在哪里
- 异步编程的底层原理还需深入（事件循环怎么工作）
- Docker 构建的缓存机制和路径规则需要多练习
